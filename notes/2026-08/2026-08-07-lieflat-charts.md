# Lieflat Charts：把 Agent 生成图表从“套模板”推进到“按阅读速度与数据契约选型”

## 1. 这是什么

Lieflat Charts 是公开的 Agent Skill：让兼容 `SKILL.md` 的 AI Agent 将数据生成可直接打开的单文件 HTML 图表。它不是单纯的图表组件库，而是把“数据语义—读者阅读速度—图型—页面叙事”写成可执行的选型流程。

仓库提供 48 个模板：Lupi Editorial 15 个、Lupi Basics 12 个、Glance 18 个、Interactive 3 个。主要用原生 SVG；快读和复杂交互模板会使用 Chart.js 或 Apache ECharts。项目创建于 2026-07-16；截至本次核验（2026-08-07）最新提交为 `842d3c7`（新增 treemap 与自定义色彩规则），说明仍在快速迭代。

## 3. 核心观点 / 核心能力

1. **先给图表分配“阅读任务”**：Lupi Editorial 用于年报、论文、长文等细读叙事；Glance 用于周报、Dashboard、汇报中的快速比较；Basics 处理常见图形但保留编辑排版；Interactive 承载网络、路径、流向等关系数据。
2. **先判断数据契约，再选图**：一张图应表达一个独立结论，保留真实数据单位、来源、旁注和必要留白，而不是把所有字段塞到同一张图。
3. **输出形态适合交付**：单文件 HTML 易于预览、转交和二次改数；纯 SVG 模板可离线运行，依赖 Chart.js/ECharts/CDN 字体的模板需要联网才能完整呈现。
4. **视觉体系有明确约束**：默认 Mono 灰阶，当前版支持在语义适配时使用内置色彩预设；强调同一交付中不要混用色彩系统。

## 4. 我学到了什么

“审美”可被部分产品化为约束，而不只是让模型自由发挥：图表品质首先来自结论粒度、数据单位、信息层级和读者的阅读场景，其次才是颜色和动效。

这比“让 Agent 生成一个好看的柱状图”更可迁移。任何业务报告生成能力都应先问：这张图给谁看、希望几秒读懂、要支持决策还是支持追溯；随后才选择图形与交互。

## 5. 它是否可信，哪些需要验证

- **已确认**：仓库公开、目录中包含 `SKILL.md`、`catalog.md`、模板、样例及校验脚本；README 清楚说明模板数量、实现方式和联网依赖；本次 API 核验显示近期仍有提交。
- **待验证**：需要在真实中文业务数据上评估文字密度、移动端导出、加载速度、无障碍性和不同 Agent 对 SKILL 规则的遵循率。
- **不宜夸大**：模板与视觉规则不能替代数据口径治理、结论判断与业务叙事；输入数据或指标定义有误时，产出只会是“漂亮但错误”的图。

## 6. 对个人能力有什么价值

- 训练“按决策任务选图”而非“按图表类型选图”的表达能力。
- 将汇报设计拆为数据准备、结论提炼、阅读速度、视觉交付四个可检查环节。
- 对 Agent 使用者而言，可把自然语言需求升级为包含受众、时长、结论和数据边界的图表 Brief。

## 7. 对企业 AI 落地有什么价值

**当前判断：不建议将该 Skill 或其 Mono 视觉体系引入公司正式图表产出。** 它的灰阶、低对比、留白和编辑叙事更像个人作品集或媒体长文，与公司常见的销售、运营、业务汇报需要的清晰、亲和、积极、品牌化表达不匹配；强行套用会产生“高级但疏离”的观感。

可保留的只有方法层启发：先明确受众、阅读时长、业务结论和数据口径，再决定图表结构。若公司后续需要建设图表生成能力，应从品牌色、业务场景、中文信息密度和常用交付渠道出发自建或选择更适配的视觉规范，而不是直接换皮复用本项目。

## 8. 当前处理

不推进接入或试点。将其作为“图表表达应先分阅读任务”的外部案例保留；待出现明确的长文/研究型内容场景时，再评估是否仅借鉴其信息层级和叙事方法。

## 9. 风险和边界

- **许可**：项目采用 PolyForm Noncommercial License 1.0.0。企业内部生产、商业交付、对外分发及基于模板的衍生作品是否属于许可范围，需先取得权利人明确授权；不能按常见开源许可证默认商用。
- **数据安全**：不得把客户、销售、财务或内部经营数据直接交给不受控的外部 Agent/在线服务；先走脱敏、最小字段和授权边界。
- **依赖可用性**：部分模板依赖 CDN 的 Chart.js/ECharts 或在线字体，内网、离线演示和国内网络环境应验证资源加载或改为本地托管。
- **可访问性与真实性**：动效和强视觉风格可能影响可读性；图表须保留数据来源、时间范围和指标口径，不以装饰替代解释。

## 10. 当前结论

这个项目的图表选型逻辑值得学习，但其视觉语言、外部依赖和非商用许可均不适合作为公司正式产出方案。当前不接入、不试点；仅保留“先按阅读任务和结论设计图表”的方法启发，未来如有研究型内容场景再做针对性评估。
