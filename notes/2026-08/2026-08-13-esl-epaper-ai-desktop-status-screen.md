# 二手电子价签改造 AI 桌面状态屏

## 1. 这是什么

抖音博主"刘大雁AI版"分享的一个低成本 AI 硬件 DIY 项目：从闲鱼（海鲜市场）花约 9 元淘来二手超市电子价签（4.2寸电子墨水屏，300×400 分辨率），刷固件后改造成一块放在桌面的 AI 状态屏，通过 Codex 辅助编写代码，实现图片生成、推送和自动化刷新三层功能。

视频原始链接：<https://v.douyin.com/zZbm_EYIk7c/>

## 2. 视频中的三层实现

| 层级 | 功能 | 具体做法 |
|------|------|---------|
| 第一层：AI 生成设计图 | 根据屏幕分辨率和颜色限制，用 Codex 生成 3-4 款显示样式 | 4.2寸、300×400、黑白或黑白红三色 |
| 第二层：图片推送写入 | 脚本调用设备接口写入图片 | 校验尺寸、色号、版本号，检查设备回执确保正确版本 |
| 第三层：自动化 | 定时/事件触发内容更新 | 早上今日看板、会议前倒计时、Codex 限额、照片、每日金句 |

核心亮点：硬件成本极低（9元起），代码由 Codex 辅助搭建，对新手友好，最终成为一个"陪伴工作的桌面小工具"。

## 3. 背后的技术生态（补充验证）

视频没有展开讲底层技术，但这个玩法并非凭空出现，而是建立在一个已经相当成熟的开源社区之上。

### 3.1 电子价签是什么

超市里的电子价签（ESL, Electronic Shelf Label）本质上就是**单片机驱动板 + 电子墨水屏**，通过基站（AP）无线更新价格。大量退役设备流入闲鱼，价格极低：

- **2.13寸**：盒马拆机款约 0.7-5 元，常见主控 DA14585、CC2460
- **4.2寸**：约 9-30 元，常见主控 NRF51822/NRF52811（蓝牙），黑白或黑白红三色
- 品牌包括汉朔（Hanshow）、保姿、BLOZI 等

### 3.2 两条改造路线

**路线 A：不换主控，刷自定义固件（视频走的路线）**

- 拆开价签背面电池仓，通过测试点烧录开源固件
- 保留原蓝牙芯片，用手机/电脑蓝牙传图
- 主流固件：
  - **TSL0922 固件**：支持蓝牙传图、日历、时钟，4.2寸黑白红三色，B站和GitHub有大量教程
  - **ATC BLE OEPL 固件**（atc1441）：兼容 OpenEPaperLink 协议，支持更多型号
- 优点：不需要额外硬件，成本最低；缺点：需要找到对应型号的固件，刷错有风险

**路线 B：换驱动板，ESP32/ESP8266 驱动**

- 拆掉原主板，换成 24Pin 通用墨水屏驱动板 + ESP8266/ESP32
- 走 WiFi，灵活性更高，可直接对接 Home Assistant
- 优点：通用性强，不受原厂主控限制；缺点：多花 10-20 元，需要接线

### 3.3 OpenEPaperLink：标准化的价签通信协议

这是视频"图片推送+回执校验"背后最关键的开源项目：

- GitHub：<https://github.com/OpenEPaperLink>
- 用 ESP32 做 Access Point（AP），价签刷固件后自动连接
- 支持图片下发、版本校验、设备回执、电量监测
- 有完整的 Home Assistant 集成：<https://github.com/OpenEPaperLink/Home_Assistant_Integration>
- 支持 AP 模式和 BLE 直连模式两种拓扑

Home Assistant 社区已经用这套东西实现了：天气看板、日历提醒、步数显示、垃圾分类提醒、电费电价展示等大量场景。

### 3.4 电子墨水屏的关键特性

- **双稳态**：刷新后断电也保持显示，功耗极低
- **续航与刷新次数挂钩**：每天刷新 1440 次（每分钟一次）比较费电；每天只刷新几次，纽扣电池可用数月甚至一年
- **三色屏（黑白红）**：红色粒子需要更高电压驱动，刷新更慢，但视觉效果好
- **适合"偶尔更新、长期展示"的信息**：这正是它适合做桌面状态屏而不是视频播放器的原因

## 4. "AI 走向硬件"这个判断为什么有道理

视频标题说"AI玩到最后会走向硬件"，这个观察值得拆开看：

1. **输出瓶颈**：当前 AI 的输出主要困在聊天窗口和网页里，需要人主动去看。电子墨水屏提供了一个**环境化的输出口**——信息"抬头就在那里"，不需要打开任何APP。

2. **成本结构变了**：9元钱的屏幕 + AI 生成内容 + 自动化推送，三件事各自独立成熟后叠加，使智能硬件的 DIY 门槛从"需要懂嵌入式开发"降低到"会跟AI对话就能搭"。

3. **AI 降低了编码门槛**：视频中的代码由 Codex 辅助生成，包括图片处理、设备通信、自动化逻辑。这意味着不懂单片机协议的人也能完成以前需要嵌入式工程师才能做的项目。

4. **信息密度的重新分配**：手机通知是"打断式"的，桌面墨水屏是"陪伴式"的。会议倒计时、今日待办、API 限额这类信息不需要弹窗提醒，放在视线余光里就够了。

## 5. 可信度评估

**已验证：**

- 二手电子价签在闲鱼/拼多多确实大量存在，4.2寸价格 9-30 元区间属实
- TSL0922、atc1441、OpenEPaperLink 等开源固件和项目真实存在且社区活跃
- 电子墨水屏双稳态、低功耗特性是成熟技术
- Home Assistant + OpenEPaperLink 集成有完整文档和大量用户案例
- B站、GitHub、立创开源平台、数码之家有大量价签改造教程

**未能验证：**

- 抖音视频本身无法直接抓取内容（页面需登录/APP），内容依据许晶晶的观看总结
- "刘大雁AI版"博主的其他作品和项目完整度未知
- 视频中具体用的是哪款价签、哪个固件、什么脚本，未看到开源仓库链接

## 6. 可做的小实验

1. **最小成本验证**：闲鱼淘一块 4.2寸 NRF52 主控价签（确认型号），刷 TSL0922 固件，用网页蓝牙传图工具测试能不能点亮
2. **接 Home Assistant**：搭一个 ESP32 AP，刷 OpenEPaperLink，接入 HA，用 YAML 模板画一个每日看板
3. **接 AI 自动化**：用 Python 脚本定时调用日历 API / Codex API，生成图片后通过蓝牙或 WiFi 推送到价签
4. **企业场景联想**：车间工位状态、会议室门口状态、库存水位提示——电子价签原本就是为"长期显示+偶尔更新"设计的

## 7. 风险和边界

- **硬件兼容性**：不同品牌、不同批次的价签主控芯片不同，不是所有价签都能刷固件，买之前一定要确认型号和主控
- **刷机变砖**：烧录错误固件可能导致设备变砖，建议先在便宜的 2.13 寸上练手
- **电池安全**：原厂使用不可充电的 CR2450 纽扣电池，改装时注意不要短路；换用充电电池需谨慎
- **不要批量采购后再试**：先买一块验证能刷、能亮，再考虑多买
- **视频信息不完整**：目前没有看到博主公开代码仓库或物料清单，复现需要自己补全技术细节

## 8. 当前结论

这个项目的价值不在于技术本身有多新——电子价签改造在创客圈已经玩了好几年——而在于它展示了一个**AI 时代的新组合方式**：用 AI 大模型写代码、用极低硬件成本做输出、用自动化把信息推到物理世界。三个成熟领域的交叉点，恰好是普通 AI 爱好者入门硬件的最低门槛路径。

如果想尝试，最省事的路径是：闲鱼淘 4.2寸 NRF52 价签 → 刷 TSL0922 或 ATC 开源固件 → 网页蓝牙传图验证 → Python 脚本对接自动化。全程不需要电烙铁。
