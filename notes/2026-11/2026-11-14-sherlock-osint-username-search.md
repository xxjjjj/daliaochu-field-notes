# Sherlock：输入一个用户名，查 400+ 平台是否有同名公开账号

## 1. 这是什么

Sherlock 是一个 Python 写的开源 OSINT（开源情报）命令行工具：给定一个用户名，
它会并行查询数百个社交/社区平台，输出该用户名在哪些平台存在公开账号及对应主页链接。
B 站短视频把它包装成"网络侦探神器"介绍，属于真实存在且长期活跃的老牌项目，不是噱头玩具。

## 2. 原始来源

- 发现入口：B 站短视频截图（作者「别管了-Pongfi」，视频标题大意"一个用户名搜 400+ 平台"）
- 资料本体：https://github.com/sherlock-project/sherlock
- 官网：https://sherlockproject.xyz
- 第三方权威评测：Bellingcat 在线调查工具包收录
  https://bellingcat.gitbook.io/toolkit/more/all-tools/sherlock

## 3. 核心观点 / 核心能力

- **原理很朴素**：本地维护一份站点配置（data.json），对每个平台拼出"假设该用户存在的
  主页 URL"，发请求看 HTTP 响应/页面特征判断账号是否存在。不需要 API key、不需要登录。
- **只做精确匹配**：不支持模糊搜索/正则，唯一变通是 `{?}` 通配符自动替换
  `-`、`_`、`.` 等分隔符（如 `john{?}doe`）。一个人在不同站用不同昵称，得分别跑。
- **只确认"账号存在"，不抓内容**：不绕过隐私设置、不登录、不读私密资料；
  需要登录才能看的主页即使标记 found 也拿不到细节。
- 支持批量用户名、结果导出 txt/csv/xlsx、Docker / pipx / brew / Kali 源等多种安装方式。

## 4. 我学到了什么（一手实测数据，2026-11-14）

- 仓库真实且健康：**111,191 stars / 12,866 forks / MIT 协议 / 2018 年创建 /
  最近一次代码推送 2026-11-13（仍在活跃维护，非归档项目）**。
- 直接拉取官方站点清单实测：当前内置 **482 个站点**（视频说"400+"属实但偏保守）。
- **国内平台覆盖几乎为零**：482 个站点里与中国相关的只有 Gitee 和国际版 TikTok，
  微博、知乎、B 站、抖音、小红书、豆瓣、贴吧、微信、CSDN、掘金、快手等全部不在列表。
  这是短视频不会告诉你、但对我们最关键的一条。
- 部分平台主动反自动化枚举（Facebook、多数约会类 App），根本查不了；
  Discord 这类用户名没有公开主页 URL 的，覆盖也极弱。

## 5. 它是否可信，哪些需要验证

- 可信度高：star 量级、MIT 协议、Bellingcat 收录、维护活跃度都交叉印证，是 OSINT 入门
  标配工具，不是仿冒/木马项目（但第三方下载仍应只走官方仓库）。
- 待验证：视频本身的演示效果未逐帧核对；短视频引流到二次封装网站/App 的情况在这类
  "神器"内容里常见，若团队成员想用，只认 GitHub 官方仓库，别装来路不明的"中文版/图形版"。

## 6. 对个人能力有什么价值

- 理解 OSINT 的基本套路：**公开信息拼 URL 探测 + 精确匹配**，没有魔法。
  同一思路可以自己用脚本对任意有固定主页结构的站点做轻量核查。
- 适合个人场景：查自己常用昵称在各平台的占用/暴露面（数字足迹自查）、
  注册新品牌/产品名前查海外平台用户名是否被抢注。

## 7. 对企业 AI 落地有什么价值（B 主线雷达观察，非待试点）

- **市场/品牌侧**：海外社媒账号画像、KOL 与竞品背调时的第一步线索工具；
  新品牌命名阶段排查海外平台用户名/账号名占用，成本几乎为零。
- **销售侧有限场景**：外贸客户背调时，用联系人常用 ID 查其海外公开社媒存在性，
  作为线索真实性的弱信号之一（只能证明"有这个账号"，不能证明身份归属）。
- **反向警示**：它的存在说明"一个用户名走天下"会暴露完整数字足迹，
  公司官方账号命名规范、员工对外 ID 管理值得纳入安全意识培训。
- 国内场景价值低：目标平台在国内时本工具基本失效，需要另找国内方案或人工核查，
  不能拿它直接服务国内获客/背调。

## 8. 可做的小实验

- 仅在明确授权/自查前提下：`pipx install sherlock-project` 后用自己的昵称跑一次，
  看个人数字足迹暴露面，体会工具边界。
- 暂不建议对真实客户/员工名单做批量枚举，未做合规评估前不进业务流程。

## 9. 风险和边界

- **合规**：工具只访问免登录公开页面，多数司法辖区用于正当目的属合法 OSINT；
  但短时间大量请求可能违反目标平台服务条款、触发风控/封 IP，用于追踪、骚扰、
  人肉等目的则有明确法律风险。公司用途需先过合规口径。
- **国内可用性差**：实测国内主流平台零覆盖，这是硬边界，勿被"400+ 平台"宣传误导。
- **结果不等于事实**：同名账号不一定是同一人（重名普遍），found 只是弱信号，
  不能作为身份判断或业务决策的唯一依据。
- 与本组已有的账号风险口径一致：只读取公开信息、不导出 Cookie、不做自动互动，
  不触碰任何需要登录或绕过风控的动作。

## 10. 当前结论

真实、活跃、高口碑的开源 OSINT 入门工具，原理透明、风险可控，作为雷达观察和
海外品牌/背调辅助有价值；但国内平台覆盖实测几乎为零，短视频的"侦探神器"叙事
放大了通用性。**定级：雷达观察 / 待验证，不在国内业务场景试点。**
