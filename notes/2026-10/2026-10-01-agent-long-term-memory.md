# Agent 长期记忆与多轮对话：问题、业内三流派与人类的解法

## 1. 这是什么

从 AstrBot 评估中剥离出的独立问题：agent 如何在多轮、跨时间对话中既不被旧信息误导，又不丢掉仍有用的旧信息。这是 2026 年 agent 领域最前沿仍未彻底解决的核心难题之一。

## 2. 原始来源

- 触发：2026-10-01 打捞处群 AstrBot 多轮对话追问
- Mem0 论文：arXiv:2504.19413（ECAI 2025）
- MemGPT 论文（伯克利）：arXiv:2310.08560
- Zep / Graphiti 论文：arXiv:2501.13956
- 综述：The State of AI Agent Memory in 2026；docs.astrbot.app/use/context-compress.html

## 3. 先分清两种"长"

- **同一场长对话（要连贯）**：大窗口+摘要压缩已解决得不错，模型不疲劳、不走神，专注度将超过人类。
- **跨长时间的事实记忆（要准确）**：事实会过期、矛盾，这才是未解决的部分。
- 结论不是"越长越拉胯"，而是：单场已不拉胯，跨期仍难。

## 4. 核心矛盾

信息保质期不由时间决定：收货地址可能三年有效，随口报价三天有效。按轮数/时间截断 = 拿钟表判断保质期，必然两头错。核心区分应是 **"记着" ≠ "采信"**：旧信息可留存，但调用时需判断是否仍成立（被新信息推翻则失效、长期未用降权、跨期引用先确认）。

## 5. 业内三流派（有成型方案，无彻底方案；2026 初共识：领域 genuinely early）

### 5.1 Mem0 —— 抽取事实 + 覆盖式更新（最轻、最主流）
- 每轮 LLM 抽耐久事实→去重→与旧事实矛盾时**直接覆盖**；存 SQL+向量+实体，下一轮语义/关键词/实体三路召回。
- Apache-2.0，可挂 21 个框架，低摩擦；四作用域 user/agent/run(或session)/app。
- 硬伤：覆盖即删除，新说法若错则旧事实丢失；纯向量时序/多跳推理弱。

### 5.2 Zep / Graphiti —— 时序知识图谱（最贴"保质期"难题）
- LLM 抽带时间戳的实体和边；新事实推翻旧事实时**不删，标记"已失效"并留历史**。时序（"上周二"）、矛盾处理、多跳推理最强。
- 硬伤：要跑图数据库、运维重；benchmark 有争议（LOCOMO：Zep 自报约 84，Mem0 复现 58.44，Zep 反驳 75.14），评测本身不成熟。
- 数据：论文称 LongMemEval 相对全上下文准确率提升达 18.5%、延迟降 90%（Zep 71.2 on LongMemEval GPT-4o，为第三方口径）。

### 5.3 Letta（原 MemGPT）—— 模型自管记忆（学术最严谨）
- 上下文窗口当内存、外部存储当硬盘，模型经函数调用自行决定记/删/调入；可编辑记忆块 + 归档库；记忆块可跨 agent 共享（同类唯一一等公民共享态）。
- 硬伤：架构锁定，agent 必须跑在其运行时，迁移=重写全部。

### 5.4 参照系：ChatGPT 记忆（"Dreaming"，2026-06）
- 后台进程通读历史、自维护更新记忆状态，体验最好；但无 API、不可导出、黑盒、锁定 OpenAI，对企业自建无参考价值。

## 6. 人类是怎么"解决"的

人类并未解决，而是靠**主动遗忘 + 不断重新确认**绕过，且容忍记错：

1. **不存原文，只存意义和感受**：一次性有损压缩，无原始记录可回放。
2. **遗忘是核心机制而非缺陷**：记忆为"辅助下一决策"服务；按**复用频率 + 情绪/后果权重**淡化，不按新旧排序。
3. **每次回忆都改写**：回忆是重新拼装并覆盖存回，无客观档案，记忆是服务当下自我的叙事。
4. **真正的解法在大脑外——社会确认**：重新问一遍（"那价格现在还算数吗"）、写下来（合同/备忘存证）、问别人（分布式记忆）、默认以"最近的你"重新校准。

完整分工：**大脑做有损提炼+重要性加权（不管准确存档），纸笔/系统存证，语言社交负责随时再确认。**

## 7. 对 Agent 设计的直接启发

- **遗忘能力比存储能力值钱**：别追求记住一切，追求忘掉不重要的。
- **重要性靠复用频率 + 后果权重，不靠时间**。
- **不能错的事实交给外部存证**（CRM、报价单、确定性计算器），模型记忆只放判断性内容。
- **不确定就自然开口确认**："我记得是 X，变了吗？"——这是当前 agent 普遍缺失的低成本社交动作。
- 破解方向三招叠加：**外部存证 + 失效标记/时间戳（Zep 路线）+ 主动再确认**；模型需要的是分清"什么该记、什么该查、什么该问"，而非永远准确记住一切。
- 纠错礼仪是隐形护城河：人记错能低成本修复（道歉、追问），客户对 AI 错一次信任即崩；做出自然的"拿不准先确认 / 上次是我记错"比追求记忆 100% 准确更实用。

## 8. 当前结论

多轮长对话的"连贯"已基本解决；"跨期事实的准确与失效"没有银弹，但从"怎么记住"转向"怎么忘掉、怎么存证、怎么敢问"，三者皆为有解的工程问题，只是尚未做透。对我们最有参考价值的是 Zep 的"留痕标失效"与人类的"再确认"，可作为后续自研记忆机制的设计基准。
